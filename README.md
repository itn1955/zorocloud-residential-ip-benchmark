## 三网实测：晚高峰到底行不行

网上的测评大多只展示闲时数据，但你真正用的时候，往往是晚上 8 点到 12 点。我们把手上能找到的实测数据整理出来，重点看晚高峰表现。

### 日本 GLBB 家宽（¥128/月）

这款产品用的是 GLBB（AS55900），日本一家小型正规家宽运营商。规模很小，主要经营住宅用户网络，限制每个 POP 的用户数来保证高峰期不卡——不过如果你的并发或连接数太高，仍然可能出现网络波动。

商家标注带宽 200Mbps，实际测试：

- **闲时广州电信**（500Mbps 家宽）→ 日本机器：上行 166-187 Mbps，下行 163-185 Mbps，延迟 51ms，0% 丢包
- **闲时广州联通**（500Mbps 家宽）→ 日本机器：上行 35.8-40.3 Mbps，下行 28.6-38.1 Mbps，延迟 168-265ms，0% 丢包
- **闲时广州移动**（500Mbps 家宽）→ 日本机器：上行 161-185 Mbps，下行 159-183 Mbps，延迟 73ms，0% 丢包

三网去程稳定，回程混合 NTT/IIJ/LUMEN。闲时联通单线程只能跑到 40 Mbps 左右，电信和移动能接近标称带宽。

测评中多次提到：**晚高峰波动很大，比较卡顿，直连勉强能用，建议作为纯落地**。如果你是拿来中转，用日本本地机器或新加坡机器做跳板，国际带宽能跑满 200 Mbps。机对拉测试显示，日本本地 RFC.JP.CO 和 DMIT.JP.PRO 测速均达 191-200 Mbps，延迟 1.5-1.8ms。但如果是国内家宽直连访问日本这台机器，晚高峰体验不会太好。

IP 质量优秀，常规流媒体基本解锁（Netflix JP、Disney+ JP、Amazon Prime Video JP、YouTube Premium JP、Dazn JP、Abema.TV、DMM TV、Hulu Japan 等），ChatGPT、Google Gemini、Claude 也能用。但 MetaAI、Spotify Registration 不可用，部分日本本土服务（Niconico、TVer、WOWOW）也解锁不了。安全得分方面，信任得分 100，VPN 得分 0，代理得分 0，威胁得分 1，欺诈得分 0，滥用得分 0，ASN 滥用得分 0.0003（Very Low）。

## 中转 vs 直连：速度差距有多大

这是竞品测评普遍忽略的一点。以日本 GLBB 家宽为例：

**国内直连**（闲时）：
- 广州电信单线程 166-187 Mbps
- 广州联通单线程 35.8-40.3 Mbps
- 广州移动单线程 161-185 Mbps

**日本本地机对拉**：
- RFC.JP.CO → GLBB：191-200 Mbps，延迟 1.5-1.8ms
- DMIT.JP.PRO → GLBB：191-200 Mbps，延迟 1.5-1.8ms

**新加坡中转**：
- V.PS 小秘书.SG → GLBB：下行 1.74 Gbps，延迟 9.7ms

可以看到，用日本或新加坡机器做中转，下行能达到 1Gbps+，而国内直连即使在闲时也只能跑到 200 Mbps 以内，联通线路更是只有 40 Mbps。如果你是晚高峰使用，直连速度会进一步下降。

马来西亚家宽同样如此：中转单线程上行可跑满 100 Mbps，下行 500 Mbps+；使用马来西亚/新加坡机器中转下行可达 1Gbps+。但国内移动直连闲时下行只能到 300 Mbps，晚高峰断流严重。

所以如果你是拿这些住宅 IP 做落地，前面再套一层中转，体验会比直连好很多。
